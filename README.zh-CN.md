# Wheel Filter

一个原生 macOS 菜单栏小工具，用于改善游戏里过于敏感的鼠标滚轮操作。

## 为什么写这个工具

在 macOS 上玩游戏时，你可能遇到过这些情况：

- 滚轮只轻轻转了一点，镜头就飞快拉近或拉远，难以控制 zoom in / out。
- 本来只想切一次武器，却一下跳过好几个。
- 用滚轮选择物品或快捷栏时，容易滚过头。

Wheel Filter 就是为这类操作体验写的：过滤多余和过于密集的滚轮事件，让指定游戏中的滚轮更容易控制。你可以按游戏开启，并选择过滤间隔；没有添加的日常应用照常接收滚动。

它是独立的菜单栏应用，不需要安装游戏 Mod 或插件。它适合事件数量过多导致的异常；如果游戏收到单个事件就移动过大，它不会缩小该事件的滚动量，因此未必能解决。

## 安装与启动

需要 macOS 13 或更高版本。目前提供源码和构建脚本，尚未发布预编译下载包。

本地构建需要 Xcode Command Line Tools，不需要完整 Xcode 或 Apple Developer 账号。没有安装工具时先运行：

```sh
xcode-select --install
```

下载源码后，在项目目录运行：

```sh
./Scripts/build-app.sh
open "outputs/Wheel Filter.app"
```

构建脚本会先运行测试，再编译应用并进行本地临时签名。调试版本使用 `./Scripts/build-app.sh debug`。两个版本输出到同一个位置，重建前请退出正在运行的应用。

启动后，菜单栏会出现鼠标图标，没有 Dock 图标。先按提示授予下方说明的「辅助功能」权限，再配置游戏。

## 使用步骤

1. **添加应用。** 将游戏切到前台，打开 Wheel Filter 菜单，核对 **Front app** 显示的名称，点击 **Add This App as a Game**。
2. **选择过滤间隔。** 打开 **Debounce**，建议先选 **50 ms**。可选 30、40、50、75 毫秒：间隔越长，过滤越强；越短，越容易保留快速主动滚动。
3. **开启过滤。** 确认 **Enable Wheel Filter** 前有勾。首次运行默认已勾选；如果已有勾，不需要再点击，否则会关闭。
4. **回到游戏试用。** 实心鼠标图标表示正在过滤。试着缩放镜头或切换武器；仍太敏感可提高间隔，主动滚动被吞掉则降低间隔。

通过 **Configured Games** 可以移除应用。游戏按 bundle ID 识别；没有 bundle ID 的程序无法添加。关闭总开关或退出应用即可停止过滤。

需要登录后自动启动时，可以在「系统设置 → 通用 → 登录项」中添加应用。

## 系统权限

| 权限 | 用途 | 设置位置 |
| --- | --- | --- |
| 辅助功能（必需） | 在滚轮事件到达游戏前拦截，并决定放行或过滤 | 系统设置 → 隐私与安全性 → 辅助功能 |

当前实现只主动请求「辅助功能」权限，不请求屏幕录制、自动化、完全磁盘访问，也不单独请求「输入监控」权限。

如果授权后仍显示 **Event tap unavailable**，点击 **Retry Event Tap**。移动应用或重新构建后，可能需要在辅助功能列表中移除旧条目，再添加当前应用。

应用没有网络请求或遥测，设置保存在本机。

## 签名与下载提示

本地构建使用 **ad-hoc 临时签名**（`codesign --sign -`）。它不是 Apple 签发的 Developer ID 签名，应用也没有经过 Apple 公证。本地构建无需开发者账号，但仍需要手动授予辅助功能权限。

如果以后把这样的 `.app` 打包上传 GitHub，其他人下载后，macOS 的 Gatekeeper **可能阻止首次打开**，提示开发者无法验证或 Apple 无法检查应用。具体文案取决于系统版本和下载文件的隔离标记。临时签名有效，不等于 Apple 认可了发布者；包装成 ZIP 或 DMG 也不会改变这一点。

如果确认信任下载来源，且系统允许覆盖，可以先尝试打开，再前往「系统设置 → 隐私与安全性 → 仍要打开」确认。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。无需全局关闭 Gatekeeper。

面向普通用户、按默认 Gatekeeper 设置分发的常规路线是 **Developer ID 签名 + Apple 公证**，需要相应的 Apple Developer Program 账号与证书。参见 [Apple 官方发布说明](https://developer.apple.com/developer-id/)。

当前推荐本地构建。预编译包可以后续作为方便选项，但需要明确标注架构，以及「仅临时签名、未经公证」。

## 适用范围

- 只在主开关开启、权限有效、拦截器运行且前台应用已添加时过滤。
- 已放行事件的滚动量保持原样；不会固定滚动距离、取消加速度或增加平滑效果。
- 已添加应用中的触控板滚动也会受到影响。
- 过快的主动同向滚动可能被过滤，可以降低间隔或关闭过滤。
- 尚未验证所有鼠标、游戏和系统版本。

## 排障

- **待机或等待添加游戏：** 检查前台应用、已添加列表和总开关。
- **镜头仍然一下移动很远：** 可能是单个事件的滚动量或游戏灵敏度；此工具不缩小单个事件的数值。
- **Finder 或 `open` 启动失败：** 可直接运行 `"outputs/Wheel Filter.app/Contents/MacOS/WheelFilter"` 排查。开发机器曾遇到 LaunchServices 启动不一致，直接执行成功不代表该问题已修复，也不能替代对下载包的 Gatekeeper 检查。

反馈问题时，请提供系统版本、鼠标型号、游戏、过滤间隔、其他鼠标工具及复现步骤。

## 开发说明

使用 Objective-C、AppKit 和 `CGEventTap`，没有第三方依赖。代码结构与详细规则见 [英文 README](README.md#development)。

实现使用垂直 line delta 判断：为零时丢弃整个事件，同向事件在间隔内丢弃，反向立即放行，其余原样放行。丢弃事件不会延长窗口。纯横向事件、line delta 为零但 point delta 非零的小幅事件也会被丢弃。

每次构建都会测试零 delta、同向时间窗口、反向立即放行及重置行为；菜单、权限和游戏内效果需要实机验证。

本项目使用 AI 编程工具辅助实现、重构和编写文档。过滤行为经过作者实际使用验证，构建脚本包含去抖算法测试；尚未验证所有鼠标、游戏和 macOS 版本。
